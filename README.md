# TelegramGdzBot

Telegram-сервис поиска учебных решений и работы с ИИ. Включает выбор класса, учебника и задания, закладки, подключение ботов, подписки, рекламные и платёжные сценарии. Построен на aiogram 2 и SQLite.

## Подготовка и запуск

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m handlers.super_main
```

Перед запуском настройте `data/config.py` и подготовьте базы в `data/databases/`. В частности, реестр токенов подключённых ботов читается из `bots.sqlite3`; нужны также данные учебников и пользовательских сервисов. Рабочие базы не входят в репозиторий. Ключи ИИ-провайдеров и YooMoney задавайте для собственного окружения.

Команды выполняются из корня проекта, чтобы были доступны пакеты `data`, `handlers` и `utils`. Redis используется вспомогательными сервисами; параметры соединений находятся в соответствующих модулях `utils/`.

## Структура

- `handlers/gdz/` — навигация по решениям.
- `handlers/gpt/` — обработка ИИ-запросов.
- `utils/` — базы, закладки, платежи, реклама и интеграции.
- `main.py` — оболочка контроля связи и перезапуска процесса; при запуске обновляет g4f.

Внешние интеграции и версии библиотек относятся к исходному окружению проекта и требуют проверки при повторном развёртывании.
